What is Algebra?

Start with the basic idea.

Algebra is a part of mathematics where letters can represent numbers.

For example, if we don't know a number, we can use a letter such as x to represent it.

x + 5 = 12

Here, x is the unknown value.

Key Ideas

These are the building blocks of algebra.

Variables

A variable is a letter or symbol that represents a number.

x = unknown number

Constants

A constant is a fixed value that does not change.

7, 12, 25

Expressions

An expression combines numbers, variables and mathematical operations.

3x + 5

Equations

An equation states that two mathematical expressions are equal.

2x + 4 = 10

Learn With Examples

See how variables work in simple problems.

Example 01

If x = 5, find the value of x + 3.

x + 3 = 5 + 3 = 8

Example 02

If y = 4, find the value of 2y.

2y = 2 × 4 = 8

⚡ Practice Challenge
