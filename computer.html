Computer Fundamentals

Start with the building blocks of every computer.

💻

Computer

A computer is an electronic machine that processes data and produces useful information.

⚙️

Hardware

The physical parts of a computer that you can see and touch.

🧠

Software

Programs and instructions that tell the computer what to do.

🗂️

Data

Raw facts and information that computers can store and process.

Inside a Computer

Important components work together to make a computer function.

🧠

CPU

The Central Processing Unit executes instructions and performs calculations.

💾

RAM

Temporary memory used by the computer while programs are running.

💽

Storage

Stores files, applications and other data for long-term use.

🖥️

Input & Output

Keyboard and mouse provide input, while displays and speakers provide output.

Programming

Programming is how we give instructions to computers.

What is Programming?

Programming means writing instructions that a computer can understand and execute.

Think → Write Instructions → Run → Get Result
🐍

Python

A beginner-friendly programming language used for applications, automation, data and AI.

🌐

JavaScript

A programming language that makes websites interactive and dynamic.

HTML

HTML creates the structure and content of webpages.

🎨

CSS

CSS controls the appearance and layout of webpages.

How Websites Work

Three technologies form the foundation of modern webpages.

HTML + CSS + JavaScript

The Internet

Understand how devices communicate across the world.

🌍

Internet

A global network connecting computers and devices around the world.

🔗

Website

A collection of webpages that can be accessed through the internet.

🔎

Browser

Software such as Chrome or Firefox used to access websites.

☁️

Cloud

Remote computers and servers used to store and process data over the internet.

Artificial Intelligence

A glimpse into one of the most important areas of modern computing.

What is AI?

Artificial Intelligence is a field of computer science focused on creating systems that can perform tasks that normally require human-like abilities such as recognizing patterns, understanding language and making predictions.

Data → Learning → Pattern Recognition → Output
